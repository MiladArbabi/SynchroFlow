# Echo Hub v1.0 Overview 💬

**Status**: Static UI Shell Implemented (Phase 6 In Progress)

Echo Hub is the unified communication command center for SynchroFlow, designed to consolidate customer interactions, provide immediate context, and streamline resolution workflows, ultimately reducing operational overhead.

---

## User Journey 🚀

The Echo Hub user journey prioritizes **speed**, **context**, and **resolution efficiency**:

1.  **Entry & Default State**:
    * User accesses via the **"Echo Inbox"** Sidenav link.
    * Loads instantly into a **three-pane layout**:
        * **Left Pane (Sources/Filters)**: Lists sources (Email, Chat, etc.) and filters (Unassigned, Mine). Defaults to a primary view (e.g., "All Unassigned").
        * **Middle Pane (Conversations)**: Lists conversations matching the filter, sorted by urgency. Shows key details (customer, subject, time, status). The top conversation is auto-selected.
        * **Right Pane (Details & Context)**: The main workspace, showing the selected conversation thread, response composer, and embedded **Context Tabs** (Conversation, Customer 360, Order 360) pre-loaded for the selected conversation. 

2.  **Triage & Selection**:
    * User scans the **Conversations Pane**, guided by visual cues (unread, timers, tags).
    * User optionally selects different filters/sources in the **Left Pane**.
    * User clicks a conversation in the **Middle Pane**. The **Right Pane** updates instantly.

3.  **Contextual Understanding & Action**:
    * User reads the conversation thread.
    * User seamlessly switches between the **"Customer 360"** and **"Order 360"** tabs within the Right Pane to get full context (LTV, order history, live WMS status, financials) *without leaving the Echo Hub*.
    * User drafts a response using the composer.

4.  **Resolution & Flow**:
    * User sends the reply and optionally updates the conversation status/assignment.
    * The system **auto-advances** to the next priority conversation in the Middle Pane, updating the Right Pane accordingly to maintain workflow momentum.

---

## Current Implementation (v1.0 - Static UI Shell) ✅

* **Page & Layout**: `/echo-hub` route exists. A responsive three-pane layout (`EchoHubPage`) using MUI Grid is implemented.
* **Left Pane (`EchoHubLeftPane`)**: Displays a static list of sources and filters with basic selection styling.
* **Middle Pane (`EchoHubMiddlePane`)**: Displays a static list of mock conversations, including avatar, name, subject, timestamp, status chip, and unread badge. Basic selection styling is present.
* **Right Pane (`EchoHubRightPane`)**:
    * Displays static mock conversation content based on the selected item in the Middle Pane.
    * Includes functional **Context Tabs** ("Conversation", "Customer 360", "Order 360").
    * Includes static **Customer Profile** and **Key Metrics** components within the "Customer 360" tab.
    * Includes placeholders for the "Order 360" tab.
    * Includes a static **Response Composer** (TextField + Button).
* **Basic Interaction**: Clicking a conversation in the Middle Pane correctly updates the content displayed in the Right Pane.
