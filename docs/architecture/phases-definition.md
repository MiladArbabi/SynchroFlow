# Framework Tiers (FT): Integration & Truth Progression

A staged model representing system capabilities and user experience constraints during integration and truth-validation phases.

---

## **FT-1: Pre-integration / Pre-truth**

*Identity exists, but the system has no prior engagement.*

- **State:** No stored data, no historical signals, no user-specific knowledge.
- **UX Approach:** Promise-based and aspirational. Communication focuses on potential value and future benefit, as no evidence from past interactions can be shown.
- **Design Note:** ✔️ Aspirational language is correct and appropriate for this stage.

---

## **FT0: Momentary Integration Handshake**

*Purely technical transition with no user-facing substance.*

- **State:** A transient, operational handoff. Epistemically empty.
- **UX Principle:** No user-facing semantics or persistent state should reside here.
- **Design Note:** ✔️ Correctly designed to be almost invisible to the user.

---

## **FT1: Readiness / Onboarding / Configuration**

*The user gates progress through active effort.*

- **State:** System is gathering data but remains **epistemically blind**—it cannot yet form validated truths.
- **UX Approach:** Interface must encourage, nudge, and instruct. User effort (e.g., configuration, data input) is the primary gating factor.
- **Design Note:** ✔️ This is the correct stage for CTAs, tutorials, and guided setup.

---

## **FT2: Unlocked Free Tier / Truth Surface**

*The system earns the right to speak, but only what it can defend.*

- **State:** System can now surface insights and statements based on validated, defendable data.
- **UX Constraint:** Communication is limited to **truth it can defend**. No persuasion, no guidance, no explanatory narrative beyond the factual.
- **Design Note:** ✔️ The interface correctly becomes "boring"—prioritizing clarity, accuracy, and defensibility over engagement.

---

**Key Insight:** This framework delineates where persuasion is appropriate (FT-1, FT1) and where it must be strictly removed in favor of defensible truth (FT2). The transition through FT0 is a technical checkpoint, not a user experience.
