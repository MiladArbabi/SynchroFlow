Services Overview:

Frontend: Vercel, connected to main branch.

Backend API: Fly.io (App: synchroflow).

Database: Fly.io Postgres (App: synchroflow-db).

Message Queue: CloudAMQP (free-tier).

Environment Secrets Checklist:

Vercel: VITE_PUBLIC_API_URL (set to https.app.lasyncro.com), VITE_PUBLIC_POSTHOG_KEY, VITE_PUBLIC_POSTHOG_HOST.

Fly.io: DATABASE_URL, RABBITMQ_URL, JWT_SECRET, ENCRYPTION_KEY, SESSION_SECRET, POSTHOG_API_KEY, FRONTEND_URL, API_URL.

Local C++ Build Fix (macOS):

A note that brew install libpq libpqxx is not enough.

You must also run export PKG_CONFIG_PATH="$(brew --prefix libpq)/lib/pkgconfig" in your terminal to fix npm install failures.

The "First-Time Deploy / Chicken-and-Egg" Guide:

This is the most important part. It documents the exact steps we just finished.

Goal: Run database migrations on a new, empty database before the app starts.

Step 1: In fly.toml, comment out the entire [[http_service]] block.

Step 2: Add [processes] app = "sleep infinity" to fly.toml.

Step 3: Run fly deploy to deploy the "sleeper" machine.

Step 4: Run fly ssh console -C "npx knex migrate:latest --knexfile apps/backend/dist/knexfile.js" to migrate the database.

Step 5: Remove the [processes] block from fly.toml and un-comment [[http_service]].

Step 6: Run fly deploy one last time to start the real app.
