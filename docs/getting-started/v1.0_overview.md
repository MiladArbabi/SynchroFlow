# Getting Started

## Introduction 👋

Welcome to SynchroFlow! This guide provides the essential steps to set up your local development environment, run the platform, and understand the basic navigation. SynchroFlow is designed as the central nervous system for e-commerce operations, unifying data and streamlining workflows.

---

## Prerequisites 🛠️

Before you begin, ensure you have the following installed on your system:

* **Node.js**: v20 or later.
* **Docker**: For running containerized services (PostgreSQL, RabbitMQ).
* **Git**: For cloning the repository.
* **C++ Compiler**: Required for the core engine (e.g., Xcode Command Line Tools on macOS, Build Essentials on Linux).
* **Python**: v3.x with `venv` for the AI microservice.
* **(macOS Specific)**: Homebrew for installing C++ dependencies.

---

## Local Development Setup ⚙️

Follow these steps to get SynchroFlow running locally:

1.  **Clone the Repository**:
    ```bash
    git clone [YOUR_REPOSITORY_URL]
    cd SynchroFlow
    ```

2.  **Install Dependencies**:
    * **(macOS)** Install C++ dependencies:
        ```bash
        brew install libpq libpqxx
        ```
    * Set up the Python virtual environment for the AI service:
        ```bash
        cd packages/ai-engine
        python3 -m venv venv
        source venv/bin/activate
        pip install -r requirements.txt
        deactivate
        cd ../..
        ```
    * Install all Node.js dependencies from the monorepo root:
        ```bash
        npm install
        ```

3.  **Initial Database Setup & Run**:
    * This command handles database initialization, migrations, and starts all services with hot-reloading:
        ```bash
        npm run dev:full
        ```
    * **Services**:
        * React UI: `http://localhost:5173` (or next available port)
        * Node.js API: `http://localhost:3000`
        * Integration Service: `http://localhost:3001`
        * Python AI Engine: `http://localhost:8000`
        * PostgreSQL DB: Accessible via Docker (typically port 5432)
        * RabbitMQ: Accessible via Docker (typically port 5672, Management UI 15672)

## First Login 🔑

1.  Navigate to `http://localhost:5173`.
2.  You should be redirected to the login page (`/authentication/sign-in`).
3.  Use the default development credentials (**TBD** - e.g., `dev@synchroflow.com` / `password`) to log in.

## Navigating the UI (v6.0+) 🧭

SynchroFlow uses an **Entity-Centric** layout:

* **Sidenav (Left)**: Provides primary navigation links to core entities (Dashboard, Orders, Customers, Products, Echo Inbox) and system commands.
* **Master Panel (Left Section)**: Displays a list view of the selected entity (e.g., a table of all orders).
* **Context Panel (Right Section)**: Shows detailed information for the item selected in the Master Panel, often using tabs (e.g., Order Summary, Customer Details, Actions).
* **Header**: Contains global actions like search, notifications, profile settings, and theme customization.
