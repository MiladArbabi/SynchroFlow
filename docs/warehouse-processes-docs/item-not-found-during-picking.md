# **Item Not Found During Picking**

---

## 1. What You’re Seeing

You go to the assigned location.

The item is not there.

---

## 2. What This Actually Means

This is not random.

One of these is true:

* item was placed in the wrong location (stow issue)
* item was picked earlier and not updated
* item is damaged or removed
* inventory record is incorrect

---

## 3. What To Do (Immediately)

Follow this exactly:

---

### Step 1 — Double Check the Location

* confirm you are at the correct shelf / bin / slot
* scan the location if applicable

---

### Step 2 — Check Nearby (Quick Only)

* check adjacent slots
* do NOT search extensively

👉 limit this to a few seconds

---

### Step 3 — Scan Any Matching Item (If Found)

If you see a similar item:

* scan it

→ system will confirm if correct or not

---

### Step 4 — If Item Is Still Not Found

→ **Log the issue in Problem-Center**

* select: “Item Not Found”
* confirm the issue

---

### Step 5 — Continue Picking

* move to the next item
* do NOT stop the workflow

---

## 4. What NOT To Do

Do NOT:

* search the entire warehouse
* guess and pick a similar item
* ask others before logging
* skip logging the issue

---

If you bypass the system:

→ the problem stays hidden
→ and will repeat

---

## 5. What Happens Next (System Behavior)

Once logged:

* issue is recorded
* linked to:

  * SKU
  * location
  * order

---

Then:

→ assigned as a **Job To Be Done**

---

This allows:

* investigation
* correction
* prevention

---

## 6. Why This Matters

If not handled properly:

* wrong items get picked
* orders are delayed
* returns increase

---

If handled correctly:

→ the system improves over time

---

## 7. Root Cause (Why This Happens)

Most common causes:

* incorrect stowing
* unlogged problem-center
* manual adjustments outside the system

---

## Key Insight

→ this is not a picking problem
→ it is usually a **stowing or inventory issue**

---

## 8. What Good Looks Like

* issue logged instantly
* no guessing
* no searching
* workflow continues

---

## 9. How To Prevent This

* follow stowing exactly
* never place items outside assigned locations
* always log problem-center
* never bypass scanning

---

## 10. Quick Action (Operator Shortcut)

```text
Item not found →
Check location →
Quick nearby check →
Log issue →
Continue
```
