# Customer 360 👤🔄

**Status**: Static UI Implemented (Phase 6 Complete)

---

## Purpose & Vision: The Cornerstone of Customer Understanding

The Customer 360 view is engineered to be the **absolute single source of truth for every customer interaction and data point** within SynchroFlow. Its mission is to eradicate the operational drag caused by fragmented customer information typically siloed across sales channels (Shopify, Amazon), support desks (Zendesk, email), and fulfillment systems. This unification is achieved by SynchroFlow's Integration Service, consolidating data into a central profile.

By presenting this unified data intelligently, Customer 360 empowers your teams—from frontline support to strategic marketing—to:

* **Deliver Hyper-Personalized Experiences**: Understand the full customer context immediately.
* **Increase Operational Efficiency**: Eliminate time wasted hunting for information across multiple tools.
* **Boost Customer Lifetime Value (LTV)**: Identify and nurture high-value customers proactively.
* **Reduce Churn**: Address issues faster and with greater insight.

---

## Layout & Information Architecture

Accessed via `/customers/:id` (e.g., by clicking a customer row on the `/customers` list page or a link in **Echo Hub**), the Customer 360 view utilizes a **multi-section layout optimized for scannability and quick access**:

1.  **Header**: Displays the Customer ID (`Details for Customer #<ID>`).
2.  **Top Row**:
    * **Profile Section (`CustomerProfile`)**: Displays core contact details, addresses, and tags in a dedicated card/paper.
    * **Key Metrics Section (`CustomerKeyMetrics`)**: Displays calculated value indicators (LTV, AOV, etc.) in a separate card/paper.
3.  **Bottom Rows**:
    * **Order History Section (`CustomerOrderHistory`)**: A card/paper containing a `DataGrid` listing the customer's past orders.
    * **Support History Section (`CustomerSupportHistory`)**: A card/paper containing a list of the customer's past support interactions.

_Visual Goal_: A dashboard-like page providing a comprehensive overview with distinct sections for different data categories.

## Current Implementation (v1.0 - Static UI) ✅

* **Pages & Routing**:
    * `/customers` route created, linked from Sidenav, rendering the `CustomersPage`.
    * `CustomersPage` implemented using `MasterPanel` and `DataGrid` to display a list of customers (fetches from mock `GET /api/v1/customers` endpoint). Clicking a row navigates to the detail view.
    * `/customers/:id` route created, rendering the `Customer360Page`.
* **Customer 360 Page (`Customer360Page`)**:
    * Implemented using MUI `Grid` layout.
    * Integrates the following static components, passing mock data:
        * `CustomerProfile`: Displays mock name, contact info, addresses, tags.
        * `CustomerKeyMetrics`: Displays mock LTV, AOV, orders, margin, last order date.
        * `CustomerOrderHistory`: Displays a mock `DataGrid` of past orders.
        * `CustomerSupportHistory`: Displays a mock list of support tickets.
* **API**: Mock endpoint `GET /api/v1/customers` created to serve the list page.

## The Central Hub: Integration with SynchroFlow

Customer 360 acts as a nexus, both consuming and providing data across the platform:

* **Echo Hub**: Customer 360 components (`CustomerProfile`, `CustomerKeyMetrics`) are **embedded directly** in the agent's context tab, providing instant background (using static data currently). Support history displayed originates from Echo Hub. [Link to Echo Hub Documentation]
* **Order 360**: Customer snapshots (`CustomerProfile`, `CustomerKeyMetrics`) are **embedded directly** in the order's summary tab (using static data currently). Order history links navigate directly *to* Order 360 views. [Link to Order 360 Documentation]
* **FinOps Command Center**: Aggregated customer metrics (LTV, AOV) will roll up into high-level business reporting (Future).
* **WMS (Indirectly)**: Shipping addresses originate from customer profiles.
* **Marketing/Segmentation (Future)**: Provides the rich dataset needed for targeting.
