# Order 360 v1.0 Overview 📄

**Status**: Foundational UI & Core Widgets Implemented (Phase 5 In Progress)

The Order 360 view provides a comprehensive, unified perspective on a single order, consolidating information from operations, finance, and customer service. It serves as the definitive, real-time dossier for diagnosing issues and taking action related to a specific order.

---

## User Journey

1.  **Entry**: Users access this view by clicking an order from the main **Orders List**, a link within **Echo Hub**, via **Search**, or from other related entities (like a Customer Profile).
2.  **Initial View (Summary Tab)**: The page loads instantly, defaulting to the "Summary" tab. This tab displays the most critical information at a glance:
    * Order ID & Timestamps
    * Live Fulfillment Status (`WmsStatusStepper`)
    * Key Financials (`OrderProfitability` widget)
    * Customer Snapshot (Name, Email, Link)
    * Items Overview (Concise summary)
    * Shipping Info (Address, Method)
3.  **Detailed Exploration**: Users switch to other tabs for specific details:
    * **Items**: Detailed list including images, SKUs, quantities, prices.
    * **Fulfillment & Shipping**: Granular WMS details, tracking numbers.
    * **Financials**: Detailed cost breakdown, payment info, fraud score.
    * **Customer**: Embedded Customer 360 context (support/order history).
    * **History/Timeline**: Audit log of order events.
4.  **Action**: Users utilize the **"Actions & Assist"** tab to:
    * Perform manual actions (refund, resend email, update address, add note, cancel, etc.).
    * Receive AI-driven suggestions (`Synchro-Assist`).

## Current Implementation vs. Goals (v1.0)

* **Implemented ✅**:
    * Basic `/orders/:id` route and `Order360Page` component.
    * `ContextPanel` shell providing the tabbed interface.
    * **Summary Tab**:
        * `WmsStatusStepper` showing live status (via mock API `GET /api/v1/orders/:id/status`). 
        * `OrderProfitability` widget showing Revenue, COGS, Margin (via mock API `GET /api/v1/orders/:id/profitability`).
    * Navigation *from* the Orders List page (`/orders`).

* **To Be Implemented ⏳**:
    * **Summary Tab**: Customer Snapshot, Items Overview, Shipping Info sections.
    * **Dedicated Tabs**: Items, Fulfillment & Shipping, Financials, Customer, History/Timeline.
    * **Actions & Assist Tab**: All manual action buttons and AI integration (`Synchro-Assist`).
    * **API Integration**: Replace all mock API endpoints with real data sources (Database, C++ Core).
    * **Cross-Module Linking**: Full integration with Echo Hub, Customer 360, Search.
