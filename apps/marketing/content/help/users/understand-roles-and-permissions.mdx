## Quick answer

LaSyncro uses three customer roles: **Owner**, **Admin**, and **Operator**.

Roles control which account, billing, settings, and warehouse actions a user can perform.

## Owner

Owners have full account authority.

Owners can:

- manage team membership;
- assign roles;
- manage billing and plan changes;
- access role and permission configuration;
- manage warehouse settings;
- use operational warehouse workflows.

Owner access is always kept on for the account.

## Admin

Admins have broad operational and administrative access.

Admins can view Team and member information.

Team membership changes are managed by Owners.

## Operator

Operators are warehouse-focused users.

The current application sends Operators back to **Warehouse** when they try to open non-warehouse areas.

Operators can use supported warehouse workflows such as receiving, stowing, picking, packing, shipping, returns, and warehouse exception handling where the workflow is available to the shop.

## Role permissions

LaSyncro starts each role with default permissions.

Some permissions can be configured at the shop level from **Role Permissions**.

Role Permissions are currently managed by Owners.

## Locked permissions

Some permissions are locked because they protect account ownership, billing authority, team membership, or core warehouse settings.

Locked permissions cannot be removed or reassigned through normal role configuration.

## When permissions and plans differ

A user can be blocked because of role access or because the current plan does not include a feature.

Role access answers: "Is this user allowed to do this?"

Plan access answers: "Does this shop have this feature?"

Use **Billing** for plan capacity and **Role Permissions** for role access.
