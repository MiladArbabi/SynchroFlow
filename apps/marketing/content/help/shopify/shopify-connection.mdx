## Quick answer

If Shopify authorization is canceled, rejected, or does not return you to a connected LaSyncro workspace, start the Shopify install again from the current **Connect store** step when that action is available.

If your store is connected but sync is not complete, check the **Catalog Sync** popover and use **Resync** if the option is available.

## If authorization was canceled or rejected

Return to LaSyncro and open the **Connect store** step.

If **Install LaSyncro from the Shopify App Store** is available, select it again and complete Shopify authorization for the intended store.

If the install action is not available on the current screen, contact support. The current Connect store screen does not provide a manual store-address form.

## If you return but connection does not complete

After a successful Shopify authorization, LaSyncro should show the sync screen while your workspace is prepared.

If you return to LaSyncro but do not see the sync screen or a connected workspace, start the install again from **Connect store** if the Shopify App Store install action is available.

If the same result repeats, contact support.

## If the store is connected but sync is incomplete

Open the sync pill in the top navigation.

The **Catalog Sync** popover shows the current sync state. If **Resync** is available, select it to request a new sync for the connected Shopify integration.

A resync request may not update the counts immediately. If sync remains incomplete after giving it time to finish, contact support.

## If the connection still fails

Contact support if:

- Shopify authorization repeatedly returns you without completing the connection;
- the install action is not available on the current Connect store screen;
- the sync remains incomplete after using **Resync**;
- Shopify shows an authorization or install error.

## Still stuck?

Contact **contact@lasyncro.com** and include:

- the Shopify store you are trying to connect;
- any error message shown by Shopify or LaSyncro;
- what happened immediately before the error appeared.
