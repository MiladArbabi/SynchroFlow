## Quick answer

LaSyncro can use QZ Tray and printer routing for supported warehouse documents and labels.

When direct printing is not available, some workflows open a PDF or browser tab instead.

Carrier shipping labels are separate from local printer routing.

## Check QZ Tray

Open **Settings -> Warehouse -> Printers** on the warehouse workstation.

The printer settings screen can show:

- **QZ Tray connected**
- **Detecting QZ Tray...**
- **QZ Tray not detected on this computer**

If QZ Tray is not detected, make sure QZ Tray is installed, running, and allowed by the browser.

## Check printer routing

Owners and admins can register printers and set defaults in **Settings -> Warehouse -> Printers**.

Current routing roles are:

- unit labels;
- invoices;
- problem bin labels;
- location labels;
- general printing.

For routed printing to work, confirm that:

- the printer is registered;
- the correct role is selected;
- the printer is the default for that role;
- the OS printer name matches the name visible on the workstation;
- QZ Tray can see the printer.

## Use the PDF or browser fallback

If direct routing does not complete, LaSyncro may open the generated PDF or document in the browser.

Use that browser or PDF view to print manually when it appears.

If the browser blocks a new tab, allow pop-ups for LaSyncro and try again.

## Unit labels, invoices, and location labels

Unit labels and invoices can route through QZ Tray when a matching default printer is configured.

Location labels can also use routed printing when the location-label printer is configured.

If one label type works and another does not, check the default printer for that specific role.

## Shipping labels

Shipping labels are generated by the connected carrier setup.

A shipping label may open as a carrier label URL in the browser.

This is different from QZ Tray printer routing.

If a shipping label fails, check carrier setup, sender address, destination address, and whether the order already has a generated label.

Pack mode does not currently ask you to choose between connected carriers for each parcel. If more than one carrier connection is active, verify the generated label before handoff.

## Reprint expectations

Do not assume every workflow has a dedicated reprint control.

When a document or label opens in the browser, use the browser or PDF print controls.

For carrier labels, review the related packing and shipping-label setup articles before handing off the parcel.

## Who manages printing

Owners and admins manage printer routing and carrier setup.

Operators can use warehouse workflows that print labels or documents, but do not manage printer routing by default.
