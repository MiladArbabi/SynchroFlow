## Quick answer

Growth-tier shops can use **Alerts -> Rules** to create alerts when matching orders arrive.

Alert Rules create matching alerts in LaSyncro.

Browser notification delivery depends on notification support and the current notification configuration.

## Open Alert Rules

Open **Alerts**, then select **Rules**.

If the Rules tab is locked, review your plan in **Billing**.

## Supported rule types

Current rule types are:

- **Every new order**
- **Order from region**
- **Order above value**

Do not use Alert Rules for conditions that are not listed in the current screen.

## Add a rule

1. Open **Alerts -> Rules**.
2. Choose a value from **Notify me when...**.
3. Enter the fields required for that rule type.
4. Choose whether to turn on **Push notification**.
5. Select **Add rule**.

The rule appears in the list after LaSyncro saves it.

## Rule fields

**Every new order** does not require additional fields.

**Order from region** requires a province code or country code.

**Order above value** requires a threshold amount.

## Remove a rule

Use the delete icon next to the rule.

Removing a rule stops new alerts from being created by that rule.

It does not rewrite historical alerts that were already created.

## Push notification setting

The rule list can show a **Push** chip when push is enabled for a rule.

The rule still creates matching in-app alerts.

Browser notification delivery also depends on browser permission, device support, and LaSyncro notification configuration.

## Who can configure rules

Owners and admins can use Alert Rules when the shop has access to the Rules tab.

Operators can respond to alerts they can see, but they do not configure alert rules.
