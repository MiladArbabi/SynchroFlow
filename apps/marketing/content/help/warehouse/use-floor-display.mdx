## Quick answer

Floor Display lets owners and admins create secure display links for warehouse TVs.

The display is read-only and designed for shared warehouse screens. It shows team pace and warehouse pipeline information without operator names.

## Create a display link

1. Open **Settings**.
2. Select **Warehouse**.
3. In **Floor Display**, select **New display URL**.
4. Enter a label, such as the screen or area name.
5. Select **Create**.
6. Copy the complete display link immediately.

LaSyncro shows the display link when it is created or rotated. Copy it before leaving the screen.

## What the display shows

The display rotates through warehouse views automatically.

Current display content includes:

- team performance;
- pipeline velocity;
- exception hotspots;
- a warehouse map.

A capacity strip remains visible across the display and includes pipeline counts such as **Awaiting**, **Picking**, **Packing**, **Ship-ready**, and shipped progress for the day.

## Active and inactive displays

The Floor Display settings list shows whether each display has connected recently.

A recently connected display shows as active. If a display has never loaded or has not connected recently, it may show as inactive or never seen.

## Rename a display

Select the display label in **Floor Display**, edit the label, and save it by leaving the field or pressing Enter.

Renaming changes the label in settings. It does not create a new link.

## Rotate a display link

Use rotate when a display link should be replaced.

Rotating immediately invalidates the old link for that display and creates a new link. Copy the new link when it is shown.

Any TV still using the old link stops updating.

## Revoke a display link

Use revoke when a display should no longer work.

Revoking permanently disables that display link. A revoked link cannot be used to load the floor display again.

## If a display does not load

Confirm that:

- the complete display link was copied when it was created or rotated;
- the display link has not been rotated or revoked;
- the TV or browser can reach LaSyncro.

If the page says the display token is invalid or expired, create or rotate a display link and use the new link.
