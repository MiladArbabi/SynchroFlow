## Quick answer

LaSyncro can generate printable PDF barcode labels for your warehouse locations.

You can print a location label individually or select multiple active locations and generate a batch label sheet.

## You do not need a separate barcode first

Every location has a location code.

LaSyncro can generate a Code 128 barcode directly from that location code, so a separate merchant-supplied barcode is not required before you print a location label.

A custom barcode can still be stored for locations that already use an existing physical barcode.

## Print an individual location label

From Floor Planning, use the available **Print barcode** action for the location you want to label.

LaSyncro generates the label as a PDF.

The generated PDF uses the location's code to identify the physical location.

## Print multiple location labels

The Barcodes area also supports batch printing.

Select the active locations you want to print and generate the label sheet.

LaSyncro creates a single PDF containing the printable locations in the selection.

Inactive locations are excluded from batch printing.

## Who can print location labels

Location-label printing requires Floor Planning write access.

Owners and admins have this access by default.

Operators do not have Floor Planning write access.

## If a location does not print

Check that the location still exists.

For batch printing, also confirm that the location is active and included in your selection.

You do not need to add a custom barcode simply to make an active location printable.

## Why location labels matter

Printed location codes give the physical warehouse and LaSyncro the same location identifier.

Place each label where operators can clearly identify the corresponding warehouse location during scanning and warehouse work.
