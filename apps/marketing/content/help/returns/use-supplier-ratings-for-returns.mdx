## Quick answer

**Supplier Ratings** is a Growth-tier returns analysis view.

Use it to compare supplier return performance and review receipt batches that may need supplier follow-up.

Supplier Ratings is an analysis signal. It does not automatically change supplier selection or reorder recommendations.

## Open Supplier Ratings

Open **Returns**.

Choose **Supplier Ratings**.

If your plan does not include Returns Analysis, LaSyncro can show the feature as an upgrade-gated view.

If there is no supplier correlation data yet, LaSyncro shows:

**No supplier correlation data yet.**

The data appears once receive jobs are completed and returns are processed.

## Review the supplier scorecard

The **Supplier scorecard** groups return performance by supplier where LaSyncro can link returned items back to received stock.

Columns are:

- **Supplier**
- **Returned**
- **Received**
- **SKUs**
- **Return rate**

If LaSyncro cannot link the data to a supplier, the row can show **No supplier linked**.

Use the scorecard to compare which suppliers are associated with higher return rates across the returned products LaSyncro can attribute.

## Review return rate per batch

**Return rate per batch** shows a product and supplier breakdown by received batch when that link exists.

Rows can show:

- **Product**
- **Supplier**
- **Batch received**
- **Returned**
- **Received**
- **Rate**

If batch data is missing, LaSyncro can show **No batch data** or **Unknown date**.

Do not assume every return can be traced to a supplier or receipt batch. Use the visible linkage shown on the page.

## Understand suspect batches

LaSyncro can flag suspect batches when return rate is high compared with the merchant's usual return pattern.

The current signal flags batches around a return rate of 15% or 1.5 times your average return rate.

When a suspect batch appears, use it as a prompt to review product quality, supplier packing, batch condition, or receiving notes.

## Use the signal with suppliers

Supplier Ratings can help you:

- prepare a credit or quality-review conversation;
- compare suppliers for the same or similar products;
- find received batches that deserve inspection;
- decide which supplier relationship needs manual review.

It does not automatically penalize suppliers, change preferred suppliers, or update reorder recommendations.

## Who should use Supplier Ratings

Supplier Ratings is intended for owners and admins.

Operators can process returned items, but supplier performance review is an owner or admin workflow.
