## Quick answer

Use **Returns -> Overview** to see return work that needs attention and to monitor return performance.

Returns aging is a monitoring signal. It helps owners and admins find return jobs that have been sitting too long, but it does not change the physical state of returned stock.

## Open Returns Overview

Open **Returns**.

Choose **Overview**.

The page can show:

- **Needs attention**
- **Returns Pulse**
- **By Product — ranked by revenue leakage**
- **By Supplier — return rate per batch** when Supplier Ratings data is available for your plan.

If there are no refunds yet, LaSyncro shows that no returns have been recorded.

## Review Needs attention

**Needs attention** highlights return work that may need follow-up.

It can include customer returns where money has been refunded but no item has been processed yet.

It can also include undelivered or return-to-sender jobs that have not been resolved.

LaSyncro ranks this work oldest first.

When a row includes **Claim**, selecting it sends you to Warehouse so the return can be processed.

## Understand aging

Aging measures how long a return job has been waiting.

The signal helps you spot returns before they sit too long without inspection, stowing, customer follow-up, or another operational decision.

Changing aging thresholds changes when return work is flagged for attention. It does not receive, stow, write off, or otherwise change stock by itself.

## Read Returns Pulse

**Returns Pulse** summarizes current return performance.

Visible metrics can include:

- recovered percentage;
- resolved return jobs;
- margin lost;
- total refunds;
- revenue refunded;
- restock rate.

Use these values as operating signals. They summarize return activity; they are not a substitute for physically processing returned items.

## Review products with high returns

The product table ranks returned products by revenue leakage.

Rows can show:

- product;
- refunds;
- units;
- revenue lost;
- margin lost;
- return rate;
- restock rate.

High return rate can point to a product, sizing, description, quality, or fulfillment issue that deserves review.

## Change Returns Aging settings

Open **Settings**, then choose **General**.

Find **Returns Aging**.

Owners and admins can set:

- **Warning after**
- **Critical after**

The default values are 48 hours for warning and 168 hours for critical.

The critical threshold must be greater than the warning threshold.

Choose **Save** after changing the values.

## Who should monitor returns

Owners and admins should review Returns Overview regularly.

Operators can process return jobs in Warehouse, but aging thresholds and return performance review are owner and admin workflows.
