## Quick answer

Open **Settings -> Billing** to review your current plan, subscription status, and usage.

Owners can start plan and payment changes where the current billing provider supports them.

Admins can view billing information.

## What Billing shows

The Billing page can show:

- current plan;
- subscription status;
- trial state;
- past-due state;
- usage meters;
- plan options;
- monthly and annual billing options for non-Shopify billing;
- **Manage billing** when an external billing page is available.

## Review usage

Usage meters show activity for the current period.

The current Billing page can show:

- orders ingested;
- shipped orders.

Each meter compares current usage to the plan allowance when the allowance is finite.

Status text can show whether usage is on track, approaching a limit, almost at a limit, or already at the limit.

## Trial and past-due states

If the shop is trialing, Billing can show how many days remain and offer the next billing action.

If payment is past due, Billing can show an update-payment action so an owner can review the payment method.

## Stripe-billed shops

Stripe-billed shops use Stripe-hosted checkout and billing portal flows.

Owners can start checkout for supported paid plans.

Owners can set up or change payment where the current Stripe flow supports it.

The **Manage billing** action opens the Stripe billing portal when the shop has a Stripe customer record.

## Shopify-billed shops

Shopify-billed shops use Shopify-hosted billing where LaSyncro can provide the billing link.

When the Shopify billing link is available, **Manage billing** opens Shopify billing in a new tab.

If LaSyncro cannot open Shopify billing, contact support.

## Add seats

Extra-seat billing is currently supported for Stripe-billed Core and Growth shops with an existing Stripe subscription.

Starter shops may need to upgrade before adding more team members.

Scale includes unlimited seats.

Shopify-billed shops may be directed through Shopify billing instead.

## Who can change billing

Owners manage plan, payment, and seat changes.

Admins can review current billing and usage, but should ask an owner to make plan or payment changes.
